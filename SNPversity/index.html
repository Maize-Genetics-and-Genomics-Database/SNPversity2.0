How to Download

  • Filtered datasets (Direct download): For the filtered datasets, click the link to the Federal Box account and identify the files to download. Check the boxes next to the files and click the download icon near the top of the page. Alternatively, click on the filename listed in one of the tables below, which is linked to the Box download page for that file.
  • Unfiltered datasets (Request Access): Send an email to John Portwood with the subject "WGS file access request". Once your request is received, you will receive a link and temporary password via email. This link will be active for 48 hours.

Download Instructions

  • Prepare Adequate Storage: Ensure you have sufficient storage space on your system for the download.
  • Use a Reliable Internet Connection: A wired connection is recommended for faster and more stable downloads.
  • Consider Using a Download Manager: For large files, a download manager can help manage the download process, allowing for pause, resume, and recovery of the download.
  • Verify Data Integrity: After download, use checksums (provided in the tables below) to verify the integrity of the downloaded files.

Overview

Welcome to SNPversity 2.0, the second generation of the SNPversity platform. Designed as an open-source visualization tool, SNPversity 2.0 enables users to explore extensive variant datasets with ease. Here's how it works:
  • Input & Output: Users can input specific genomic intervals and select the species of interest. SNPversity 2.0 processes this input to deliver a Variant Call Format (VCF) file and a detailed table. These outputs showcase the alleles matching the user's query, providing a clear and concise visualization of genetic variations.
  • Technical Architecture: At its core, SNPversity 2.0 is powered by a robust HDF5 database back-end that manages variant annotations efficiently. A data exchange layer, developed in Python, facilitates seamless data handling, while a JavaScript-based interface layer presents Single Nucleotide Polymorphisms (SNPs) and Insertions/Deletions (INDELs) in an interactive format.
  • Real-Time Visualization: SNPversity 2.0 elevates data presentation by displaying information in real-time directly in your web browser. Tables are intuitively color-coded, reflecting each SNP's allelic status and mutational state for straightforward interpretation.
  • Enhanced Data Insights: Beyond basic variant data, SNPversity 2.0 enriches your research with valuable metadata. This includes variant effect annotations, mapping quality scores, genotypic coverage, and maximum R2 scores to indicate linkage disequilibrium, offering a comprehensive view of genetic variations.
  • Genomic Dataset: This version leverages a variant dataset encompassing 513 strains of Fusarium graminearum. These accessions are aligned to the Fusarium graminearum PH-1 (NRRL 31084), ensuring a broad and relevant genetic foundation for analysis.

Code

For information about the code used in SNPVersity 2.0 please refer to the GitHub page. This page provides detailed information about web compatibility, the directory structure, system requirements, and a comprehensive description of the code. It also offers guidance on how to use the websites, information about the pipelines used, and instructions on preparing data for PanEffect.

For more details, please visit our GitHub page: GitHub - SNPVersity 2.0.

How to use the website

There are four tabs in the SNPversity 2.0 website 'Select options', 'Table view', 'Tree view', and 'Help'.

Select options

The main inputs for this tool are selecting the reference genome, genomic interval of interest, and which subset of species to include.

Select genomic interval:
This section allows the user to select the genomic interval of interest. The two main options are entering the genomic coordinates or entering a gene model identifier.
  • Genome Version: Select the reference genome version. The only option currently available is B73 version 5.
  • Dataset: Select the variation dataset to query. The 'F. graminearum 2024 High Quality' dataset was built on 513 different strains of Fusarium graminearum and was filtered on mapping quality (>= 40), genotypic completeness (>= 50%), and linkage disequilibrium with max R2 > 0.5. There were approximately 3.1 million annotated loci in this dataset. The 'F. graminearum 2024 2024 High Coverage' dataset was built on 513 different strains of Fusarium graminearum and was filtered only on mapping quality (>= 40) and genotypic completeness (>= 50%). There are approximately 3.5 million annotated loci in this dataset.
  • Chromosome: Select the chromosome.
  • Genome Start Position (bp): Select the start position on the chromosome.
  • Genome End Position (bp): Select the end position on the chromosome.
  • Loci per page: Select the number of loci to view per page in the HTML table view. This number corresponds to the number of rows in the table.
  • Gene Model ID: Optionally, select the gene model identifier and the number of base pairs to add as padding to the start and end of the gene model coordinates. Pressing the 'Load coordinates' button will load the chromosome, start, and end positions if the gene model is found. This option currently only accepts B73 RefGen_v5 gene models.
(NOTE: Genomic regions larger than 1 MB will only be avaialble as VCF downloads. The table and tree views will not be available.)

Select which accessions to include:
This section allows the user to select a subset of the Fusarium graminearum strains to view. The two main options are to upload a file with the strain IDs, use the buttons to randomly subsample the datasets, or use the checkboxes to manually select the Fusarium strains. A list of all F. graminearum strains can be found in XLSX.

Zero-shot score to estimate mutation effect

We used DNABERT-2 (zhihan1996/DNABERT-2-117M), a 117 M-parameter transformer-based DNA language model built on the original BERT framework, to score mutation effects in our VCF datasets via a zero-shot protocol. In brief, we compute the log-likelihood difference (ΔLL) between reference and alternative k-mer contexts—more negative ΔLL values indicate likely deleterious changes, capturing sequence conservation learned during unsupervised pre-training on genomes from 135 diverse species. This zero-shot approach lets us flag potentially harmful SNPs across our cohorts without any further fine-tuning. Scores are available for SNPs only (INDELs excluded).

Zero-shot score to estimate missense mutation effect

We used esm-variants, a tool based on the ESM1b protein language model, to estimate variant effect scores for all missense variants in our VCF files. The tool calculates a log-likelihood ratio difference between each variant and its reference amino acid sequence, highlighting potential functional consequences. Variants with scores above -7 are generally considered benign, while those below -7 may suggest functional effects. The scores are available for missense variants only.

VCF Download from Search

After completing a search based on a genomic region and a subset of accessions, a "Download the VCF file" button will be available in the "Table view" tab. When the user clicks this link, a subset of the variants meeting the search criteria will be downloaded as a VCF file. The VCF will only include the specified set of Fusarium species and each variant within the selected genomic region. The VCF will contain rows with no variant relative to the reference. The genotype coverage fields (CVC and CVP) will refer to the number of accessions with genotype data for a particular variant based on all 1,525 accessions, not the local genotype coverage of the selected accessions.

Tree view

The tree view option allows the user to generate phylogenetic tree views based on the VCF2PopTree tool. The input to build the tree is based on the VCF file generated from the select options tab.

The tree tree can be constructed as either an UPGMA tree or Neighbour-Joining tree (Unrooted). The drawing options are inlcudes Rectangular tree or Radial tree. In addtion, the trees can be saved in the following text formats: Newick tree, Pair-wise diversity (MEGA), or PHYLIP.

Impact Meaning Example
HIGH The variant is assumed to have high (disruptive) impact in the protein, probably causing protein truncation, loss of function or triggering nonsense mediated decay. stop_gained, frameshift_variant
MODERATE A non-disruptive variant that might change protein effectiveness. missense_variant, inframe_deletion
LOW Assumed to be mostly harmless or unlikely to change protein behavior. synonymous_variant
MODIFIER Usually non-coding variants or variants affecting non-coding genes, where predictions are difficult or there is no evidence of impact. exon_variant, downstream_gene_variant
